## 상담 신청 폼

현재 폼은 작성한 내용을 화면에 정리해 보여 주고, **전화 또는 메일로 보내는 방식**입니다(서버가 없기 때문).
자동 접수를 켜려면 `index.html` 아래쪽 스크립트에서

```js
var ENDPOINT = '';
```

에 접수 API 주소를 넣으면 됩니다. 예를 들어 Formspree 주소를 넣으면 제출 시 바로 전송됩니다.
(무료 Formspree는 가입 후 엔드포인트를 발급받고, 첫 제출 때 메일로 오는 확인 링크를 한 번 눌러야 동작합니다.)

## 광고 유입 경로 기록

파워링크·키워드 광고의 `n_query`, `n_media`, `utm_*` 같은 주소 파라미터를 자동으로 읽어
상담 신청서와 메일 본문에 `유입 경로: 검색어: 대구세무사` 형태로 함께 담습니다.
광고를 집행할 때 최종 URL에 파라미터가 붙어 있으면, 어떤 키워드로 문의가 들어왔는지 바로 확인할 수 있습니다.
